# Local design assets

Instrument Sans is the selected font, downloaded from the official
[Google Fonts directory](https://github.com/google/fonts/tree/main/ofl/instrumentsans).
The unchanged variable TTF supports the selected400/500 weights.
Its SIL Open Font License is beside the source and copied into public/fonts so
the built application distributes the license with its font.

Font SHA256: `b24f1812584816958afcf22e22d08e44318c5e51651e25d2438efdde389b33b1`.

The grain SVG is a local static turbulence pattern. Navigation paths are original
line drawings from the approved design specimen; no reference-site assets copied.
